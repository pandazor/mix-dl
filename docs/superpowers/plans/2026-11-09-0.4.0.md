# dl-manager 0.4.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Licence, connexion OAuth guidée et plusieurs sites nommés.
**Architecture:** Réutiliser gallery-dl et le coffre ; ajouter un service OAuth transitoire et des définitions de sites dans Settings.
**Tech Stack:** Go, Wails, SQLite, TypeScript, Chrome/Playwright.
**Spec:** docs/superpowers/specs/2026-11-09-0.4.0-design.md

## Global Constraints
Préserver data/downloads. Trois commits : licence seule, OAuth, sites/version 0.4.0. Identifiants secrets exclusivement transitoires ou coffre. Aucun login réel automatisé. Une session OAuth de 5 minutes. Domaine du site immuable. Maintenir les sauvegardes v1.

## Review Focus
- Fermeture du dialogue pendant start/result : aucune réponse tardive dans un autre compte.
- Sortie moteur contenant des tokens dans une erreur : aucun reflet API/journal.
- Deux sites dont les domaines se ressemblent : compte/cookies jamais associés par suffixe non délimité.
- Import de sites existants : noms, chemins et défauts préservés sauf remplacement explicite.
- Renommage/reprise : pas de nouveau chemin implicite pour les tâches commencées.
