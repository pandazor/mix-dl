# Correctifs 0.3.1

Demande : le global doit être repris par les sites hérités, l'export doit fonctionner pendant les téléchargements, la croix doit quitter. Instagram avec cookies est validé par l'utilisateur.

Diagnostic : le global enregistré de l'instance testée reste le chemin initial, les deux sites ont une destination explicite. Le choix du dossier global exigeait un bouton situé tout en bas ; quitter la page perdait la saisie. L'export appelle WithIdle, qui exige running=false même sans tâche active. La fermeture Windows appelle Hide et annule WindowClosing.

Choix d'implémentation : sauvegarder automatiquement le seul dossier global (route partielle sous verrou), afficher l'état enregistré/erreur et conserver le bouton global pour les autres options. Une case explicite Utiliser le dossier global affiche le chemin effectif et enregistre une destination vide pour le site. Conserver les anciens dossiers personnalisés ; aucun déplacement ni modification des tâches commencées.

Export : photographie cohérente des sites/comptes sous verrou partagé avec leurs mutations, sans arrêter les moteurs. Chiffrement et écriture après libération du verrou. Import : conserve la pause requise car il modifie les réglages ; bouton de pause dans le dialogue, attente explicite de l'arrêt.

Fermeture : croix et Quitter passent par app.Quit et manager.Close ; le bouton arrière-plan conserve Hide/Minimise. Vérifier avec un processus de test isolé.

Alternatives écartées : dupliquer le chemin global dans chaque site figerait l'héritage ; réinterpréter les anciens chemins écraserait des choix personnels ; supprimer tout verrou d'export permettrait des instantanés incohérents. Ces choix techniques sont ceux de l'implémentation, dans le périmètre demandé.

Contraintes : Go/Wails et TypeScript existants, format chiffré inchangé, aucun accès aux secrets réels, préserver data/downloads et l'instance utilisateur. Version 0.3.1 et archives Windows/Linux, sans déplacer les tags ni modifier une release existante.
