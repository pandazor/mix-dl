# dl-manager 0.4.0

- **Licence AGPL-3.0-only** pour le code de dl-manager, dans un commit dédié. Texte LICENSE inclus dans les paquets ; licences tierces conservées.
- **Générer le token** pour Tumblr et DeviantArt : connexion et autorisation manuelles dans le navigateur, récupération des tokens dans les champs, puis enregistrement explicite du compte. Annulation, délai de cinq minutes et arrêt à la fermeture.
- **Plusieurs sites personnalisés** : nom, domaine, reconnaissance automatique des liens, comptes cookies et réglages distincts. Renommage sans changer les dossiers ; suppression protégée lorsqu'un compte ou une tâche utilise la fiche.
- Sauvegardes chiffrées étendues aux sites personnalisés, import des anciens fichiers conservé.
- Les corrections 0.3.1 et 0.3.2 sont incluses : héritage global, export pendant les téléchargements, croix/quitter, erreurs visibles et quota Tumblr expliqué.

La connexion guidée n'augmente pas le quota partagé Tumblr. Les identifiants d'une application Tumblr personnelle ne sont pas encore pris en charge. Un site personnalisé doit rester compatible avec gallery-dl.

Pour mettre à jour : quitter complètement dl-manager, sauvegarder et conserver `data` et les téléchargements, puis extraire le paquet Windows ou Linux. Voir VALIDATION.md pour les essais réalisés et les limites natives.
