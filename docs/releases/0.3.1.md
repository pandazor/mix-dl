# dl-manager 0.3.1

Correctifs après les essais réels de Rule34 et Instagram.

- Dossier global enregistré automatiquement après modification ; les sites hérités affichent et suivent le chemin global. Case explicite **Utiliser le dossier global** dans chaque site.
- Export chiffré des sites et comptes possible pendant les téléchargements, sans mettre la file en pause.
- Import de sauvegarde : bouton de pause et état de l'arrêt dans le dialogue.
- La croix quitte l'application ; le bouton **Réduire en arrière-plan** conserve l'application ouverte.

Les dossiers personnalisés existants sont conservés. Pour un site qui doit suivre le global, cocher la case et enregistrer ses réglages. Les tâches déjà commencées gardent leur destination pour la reprise.

Télécharger le ZIP Windows x64 ou le TAR.GZ Linux x64. Pour mettre à jour, quitter complètement l'ancienne version, sauvegarder et conserver le dossier data et les téléchargements. Aucun déplacement automatique des fichiers.

Instagram : cookies et téléchargement d'images confirmés par l'utilisateur sur 0.3.0. Voir VALIDATION.md pour les tests et limites de cette version.
